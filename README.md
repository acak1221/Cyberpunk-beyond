# Night City // RED

Двуязычный (RU/EN) помощник для настольной ролевой игры **Cyberpunk RED**: создание персонажей, лист персонажа с бросками, справочник правил со ссылками на страницы книги, бой, NET, медицина, ремонт, снаряжение, инструменты ведущего и чтение своей PDF-копии книги правил.

- **Без регистрации и серверов.** Все данные хранятся только в вашем браузере (`localStorage`).
- **Работает офлайн** и устанавливается на телефон/компьютер как приложение (PWA).
- **Резервные копии и обмен** — через JSON-файлы («Персонажи → Резервная копия / Импорт копии», экспорт персонажа) или ссылкой: кнопка «Ссылка» на листе копирует ссылку, по которой персонажа можно импортировать на другом устройстве (данные идут в части адреса после `#` и на сервер не отправляются).
- **Три вида оформления:** «Обычное» (по умолчанию), «Досье» и «Киберпанк» — переключатель внизу меню; у первых двух есть светлая, тёмная и автоматическая тема.
- **«Досье»** раскладывает лист как планшет персонажа: сверху ряд характеристик, слева состояние и колонка навыков, которая всегда на виду, справа панель с вкладками (бой, снаряжение, роль, жизнь). На телефоне это те же вкладки по одному разделу. Рамки со срезанными углами нарисованы в самих стилях, без сторонних картинок и шрифтов.

### Что внутри

- **Лист персонажа по вкладкам** (Основное, Навыки, Бой, Снаряжение, Роль, Жизнь, Весь лист) с закреплённой плашкой HP / Humanity / LUCK.
- **Броски в один тап:** на каждой кнопке навыка — готовая прибавка (`+8`), на вкладке «Бой» — инициатива, уклонение, рукопашный бой и спасбросок от смерти; результат показывается крупной карточкой с отметкой крита/провала.
- **Кубики:** проверка навыка, свободный бросок и кнопки урона 1d6…6d6, 1d10, 2d10; в карточке броска видны грани кубиков, на Android — короткая вибрация (отключается на странице «Кубики»); история бросков.
- **Следующий бросок:** на кнопках — число, которое реально прибавится (характеристика с учётом брони, навык, штраф ранения); рядом задаются модификатор (сбрасывается после броска, можно закрепить), трата LUCK и DV — результат сразу показывает успех или провал. У стрелкового оружия выбирается дистанция по таблице со стр. 173.
- **Правила считаются сами:** критические ранения, установленные импланты (Kerenzikov, Pain Editor, сканеры и др.) и уличные наркотики меняют броски листа, MOVE и инициативу; ситуативные эффекты показаны как напоминания. На листе есть репутация с броском Facedown и тест стиля игры.
- **За столом с телефона:** быстрое изменение HP по тапу на ♥, компактные строки оружия, «режим игры» (характеристики и навыки не меняются случайным касанием), переключатель «Не гасить экран».
- **Оружие и опыт:** счётчик патронов у каждого оружия (−1, очередь −10, перезарядка), кнопка «+» у навыка для повышения за Improvement Points.
- **Создание персонажа:** Complete Package, Streetrat, Edgerunner, пустой лист; жизненный путь и ролевые жизненные пути.
- **Справочник:** правила со ссылками на страницы, навыки и шкала сложности с шансами успеха, словарь уличного сленга, каталог снаряжения.
- **Бой, NET, медицина, ремонт, заработок, образ жизни** — отдельные инструменты по главам книги; их броски попадают в общую историю и в ленту комнаты.
- **Доступность:** работает с клавиатуры и скринридера (названия кнопок бросков, ссылка «К содержимому», фокус не теряется), контраст проверен на всех экранах; оформление по умолчанию не обращается к сторонним серверам за шрифтами.
- **Ведущему:** репутация и facedown, NPC из книги и своя библиотека NPC (добавление в бой пачкой с автонумерацией), урон/броски NPC, случайные встречи, генератор Ночного рынка, счётчики, таблицы и погода, кампании с трекером инициативы и журналом сессий (экспорт в Markdown).
- **Кампании:** трекер инициативы с закреплёнными «Назад» и «Следующий ход», состояниями ранения, уроном сквозь броню и Death Save для противников, книжные противники пачкой с нумерацией и заметкой о броне и оружии, встреча из таблицы сразу в бой, план сценария по схеме битов (стр. 395–407), журнал с экспортом.
- **Подготовка к игре:** результаты случайных таблиц (в том числе трёх книжных — стр. 326, 331, 332), погода и Ночной рынок сохраняются на устройстве и одной кнопкой записываются в журнал кампании.
- **Книга:** откройте свой PDF Corebook — оглавление, поиск по тексту и закладки работают локально.
- **Магазин с корзиной:** в каталоге закреплена плашка с покупателем и его деньгами; вещи складываются в корзину, видно, сколько останется, оплата — одним действием и сразу на лист. Рядом остаётся «Добавить бесплатно».
- **Кошелёк:** деньги видны в шапке листа и на вкладке «Снаряжение». По нажатию — «получил / потратил» с заметкой, журнал операций, точная сумма, передача другому персонажу и раздел выплаты на группу. Новый персонаж платит в каталоге из стартового бюджета.
- **Инвентарь без ручной бухгалтерии:** компактные строки, удаление с возвратом, продажа и передача предмета, броня надевается после покупки, имплант ставится в два нажатия с автоматическим максимумом Человечности.
- **Бой с листа:** прицельный выстрел, автоогонь, подавление, гранаты, рукопашная, быстрый ввод полученного урона с отменой, перезарядка неполного магазина, штраф критического ранения в спасброске от смерти.
- **Между сессиями:** «Начало сессии» (LUCK), больница, терапия, образ жизни и жильё списывают деньги из кошелька, заработок приходит в него.
- **Ведущему:** бросок атаки и урона противника из строки трекера, урон персонажу через его броню, награда eb и опыта всей группе одним действием; онлайн всё это уходит игроку как предложение, которое применяет его устройство.
- **Свои материалы:** собственные предметы, импланты и противники — в каталоге и в трекере наравне с книжными, с экспортом в файл, которым можно поделиться.
- **Импланты в один тап:** Grafted Muscle, Linear Frame, Skin Weave и Subdermal Armor применяются к листу и отменяются кнопкой; у включаемых имплантов (Sandevistan и др.) — переключатель со счётчиком раундов.
- **Схема боя:** сетка в кампании, связанная с трекером: фишки участников, расстояние и СЛ выстрела, подсветка хода и бега, укрытия.
- **Кампания целиком:** экспорт и импорт кампании одним файлом (участники, часы, журнал, схема); записи журнала можно открыть игрокам в комнате.
- **Перенос и копии:** весь архив — файлом или с устройства на устройство по короткому коду, с предпросмотром, что добавится; напоминание о резервной копии.
- **Печать:** аккуратный лист для печати или PDF и краткая карточка персонажа для ведущего.
- **Первый запуск:** короткое знакомство, готовый персонаж-пример и пробный бой, которые потом убираются одной кнопкой.
- **Вкладки «Досье»:** «Действия» (броски, оружие, урон, инструменты роли — с фильтрами Все / Атаки / Броски / Роль / Прочее / Боезапас), «Снаряжение», «Особенности» (способность роли и всё, что действует сейчас), «Персонаж»; навыки — отдельной колонкой одним списком.
- **Оформление «Досье»:** панель подробностей — тап по характеристике, навыку или оружию показывает, из чего складывается бросок, и бросает именно это число; фильтры на вкладке боя.
- **На телефоне:** нижняя панель навигации, выдвижное меню всех разделов, кнопка «Назад» возвращает к предыдущему разделу.

## Игра с друзьями (раздел «Игра онлайн»)

1. **Ведущий:** «Игра онлайн» → имя, кампания для трекера инициативы → «Создать комнату» → «Скопировать ссылку» и отправить её в чат группы.
2. **Игроки:** открывают ссылку (код подставится сам), вводят имя, выбирают своего персонажа → «Войти в комнату».
3. Дальше всё видно в реальном времени: HP, Humanity, LUCK и броня персонажей; порядок инициативы и чей ход (из кампании ведущего); счётчики ведущего; все броски с листов и со страницы «Кубики» — в общей ленте и во всплывающих уведомлениях. Броски без связи ставятся в очередь и отправляются, когда связь вернётся.
4. **Лист ведущему:** игрок нажимает «Отправить лист ведущему» — ведущий видит его в «Присланных листах» и принимает (лист сохраняется у ведущего и добавляется в кампанию; повторная отправка обновляет копию). Лист дополнительно шифруется ключом, который есть только у открытой страницы ведущего, поэтому другие игроки комнаты его прочитать не могут.
5. Пригласить за столом удобно кнопкой **QR** в комнате — игроки наводят камеру телефона.
6. **В бою:** ведущий может скрыть противника от игроков (кнопка в «Действиях» участника трекера) — в комнате его не видно, пока он не раскрыт; когда ход переходит к персонажу игрока, тот получает уведомление «Ваш ход» с вибрацией. Бросок инициативы с листа игрока сам записывается в трекер ведущего, а рядом с персонажем в трекере видны его текущие HP.
7. **Без листа тоже можно:** игроку достаточно войти в комнату с персонажем. Его бросок инициативы сам добавляет его в трекер ведущего (или ведущий нажимает «В трекер» в блоке «Игроки в комнате»), и сигнал «Ваш ход» приходит как обычно — пока ход за игроком, это видно и на значке комнаты в шапке. Когда лист всё же прислан и принят, строка становится строкой этого персонажа.
8. **Выдать игроку:** ведущий нажимает «Выдать» на карточке игрока (или «Выдать всем игрокам») и отправляет урон, лечение, деньги, IP или предмет. Игрок видит предложение на любой странице и нажимает «Применить»: урон считается через броню его листа, деньги проходят через кошелёк с записью в истории, IP попадают в журнал опыта, предмет — в снаряжение. Ведущий получает ответ, применил игрок или отклонил. HP игрока, который в сети, в трекере ведущего показаны с его листа и не редактируются — чтобы изменить их, используйте «Выдать».
9. Лента бросков и ещё не принятые листы переживают перезагрузку страницы.

Как это устроено: без регистрации и без базы данных. Каждое сообщение шифруется (AES-GCM) ключом, выведенным из кода комнаты, прямо на устройстве, и пересылается через несколько бесплатных публичных MQTT-серверов одновременно (shiftr.io, EMQX, HiveMQ) — они видят только зашифрованные байты, а если один недоступен, работают остальные. Листы персонажей остаются на устройствах владельцев; в комнату уходит только краткая сводка выбранного персонажа (и портрет, если не отключён). Зашифрованная копия вашего статуса хранится на серверах-ретрансляторах, пока вы в комнате, и заменяется отметкой ухода, когда вы её покидаете; устаревшие копии с разных серверов не перезаписывают более свежие данные. Войти может любой, у кого есть код, — делитесь ссылкой только со своей группой.

### Что защищено, а что нет

- **Содержимое сообщений** читают только те, у кого есть код комнаты. Серверы видят зашифрованные байты, дополненные до нескольких фиксированных размеров, так что по длине не отличить бросок от статуса.
- **Выдать себя за другого нельзя.** Каждое устройство подписывает свои сообщения собственным ключом; он создаётся в браузере и не покидает его.
- **Ведущий — владелец ключа из ссылки на комнату.** Инициативу, счётчики и ответы о присланных листах приложение принимает только от него; тот, кто лишь называет себя ведущим, показан как игрок с пометкой. Если входить по одному коду, без ссылки, приложение запомнит первого ведущего, которого встретит: сверьте ключ (12 знаков на странице комнаты) голосом.
- **Лист, отправленный ведущему,** зашифрован вторым ключом, который есть только у его открытой страницы.
- **Выдача от ведущего** (урон, лечение, деньги, IP, предмет) принимается только от ведущего с ключом комнаты и только адресованная этому устройству; со-ведущий и игроки выдавать не могут. Она ничего не меняет сама: игрок видит, что предложено, и применяет или отклоняет. Числа проверяются и ограничиваются на устройстве игрока. Как и броски, выдача зашифрована кодом комнаты, то есть другие участники комнаты технически могут её прочитать.
- **Строка в трекере «из комнаты»** появляется от броска инициативы любого участника комнаты с персонажем (не больше одной на персонажа); ведущий может удалить её, а лишнего участника — скрыть.
- **Чего нет.** Любой, кто узнал код комнаты, может войти как игрок: видеть сводки персонажей и броски и присылать свои. Такого участника можно убрать у себя кнопкой «Скрыть» на его карточке; чтобы избавиться от него совсем, создайте новую комнату и разошлите новую ссылку.
- **Серверы видят,** что устройство подключено к комнате и когда оно что-то отправляет, но не что именно. Это бесплатные публичные серверы без гарантий доступности.
- **Передача роли ведущего.** Ведущий может передать роль участнику комнаты (тот подтверждает, сверив короткий ключ) или назначить помощника, который ведёт инициативу и счётчики; помощника можно снять. Передача подписывается ключом прежнего ведущего, поэтому игроки принимают нового без новой ссылки.
- **Файл ведущего** позволяет продолжить игру с другого устройства. Он не одноразовый и не отзывается: храните его как пароль, а после смены устройства разошлите новую ссылку — входящие по старой ссылке доверяют прежнему ключу. Только что вошедший участник до ближайшего сообщения ведущего (до 45 с) может принять недавно снятого помощника.
- **Смена браузера у ведущего** (или очистка его данных) без файла ведущего меняет ключ: игрокам понадобится новая ссылка.
- **Версии.** Страницы со старой и новой версией приложения друг друга в комнате не видят; приложение подскажет, что кому-то нужно обновить страницу.

Свой сервер (необязательно): в консоли браузера выполните
`localStorage.setItem('nightcity-red-room-brokers', JSON.stringify([{url:'wss://ваш-сервер/mqtt'}]))` — у всех участников комнаты список серверов должен совпадать хотя бы в одном адресе.

## Хостинг

Сайт полностью статический: после `npm run build` в папке `dist/` лежит всё, что нужно разместить на любом хостинге.

### GitHub Pages (основной вариант, бесплатно)

Workflow `.github/workflows/deploy.yml` на каждый push в `main` прогоняет тесты, собирает сайт и публикует его.

Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем перезапустите workflow (Actions → «Test and deploy to GitHub Pages» → Run workflow) или сделайте push в `main`.

Адрес сайта: `https://<пользователь>.github.io/<репозиторий>/` — для этого репозитория `https://acak1221.github.io/Cyberpunk-beyond/`.

### Vercel / Netlify / Cloudflare Pages

- **Vercel:** импортируйте репозиторий — настройки берутся из `vercel.json` (сборка `node scripts/build.mjs`, папка `dist`). Переменные окружения не нужны; старые переменные Supabase можно удалить.
- **Netlify:** настройки в `netlify.toml`.
- **Cloudflare Pages:** команда сборки `node scripts/build.mjs`, папка вывода `dist`.

## Разработка

Нужен только Node.js 20+; зависимостей нет.

```bash
npm run dev       # http://127.0.0.1:5173 — исходники из site/ без кэша
npm test          # проверка синтаксиса + ~1500 тестов (node --test)
npm run e2e       # проверки в настоящем браузере: все экраны, клавиатура, офлайн, комната, доступность
npm run build     # сборка в dist/ (с service worker для офлайна)
npm run preview   # сборка и просмотр dist/ на http://127.0.0.1:4173
```

Для `npm run e2e` нужны Playwright с Chromium, а для проверок комнаты и доступности — `aedes`, `ws` и `axe-core`; точные версии и команды установки — в начале `tests/e2e/run.cjs` и в `.github/workflows/deploy.yml`. Без этих пакетов соответствующие проверки пропускаются.

| `site/room.js`, `site/room-transport.js` | «Игра онлайн»: шифрованные комнаты через публичные MQTT-серверы |
| `site/rules.js`, `site/catalog*.js`, `site/defenses-extra.js` | Справочник правил и каталог снаряжения |
| `site/*-tools.js` | Отдельные модули: бой, NET, медицина, ремонт, ведущему и т. д. |
| `site/book*.js`, `site/vendor/pdfjs` | Чтение и поиск по своей PDF-копии книги (pdf.js) |
| `scripts/` | Сборка, локальный сервер и проверка |
| `site/native.css`, `site/light.css`, `site/board.css` | Оформления: «Обычное» и его светлая тема, «Досье» (надстройка над «Обычным»); без класса на `<html>` — «Киберпанк» |
| `site/rolls.js` | Общий сервис бросков: броски инструментов попадают в историю и в ленту комнаты |
| `tests/` | Тесты модулей и интеграции (`node:test`) |
| `tests/e2e/run.cjs` | Браузерный набор для CI (Playwright); пакеты для него ставятся только там |

## Данные и перенос

Данные лежат в ключе `nightcity-red-v1` в `localStorage` выбранного браузера и сайта. Если сменили браузер, устройство или адрес сайта — экспортируйте резервную копию на старом месте и импортируйте на новом. Если сохранённые данные не удалось прочитать, приложение откладывает исходную копию в `nightcity-red-v1:recovery` и предлагает скачать её.
