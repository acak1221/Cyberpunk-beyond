# Night City // RED

Двуязычный (RU/EN) помощник для настольной ролевой игры **Cyberpunk RED**: создание персонажей, лист персонажа с бросками, справочник правил со ссылками на страницы книги, бой, NET, медицина, ремонт, снаряжение, инструменты ведущего и чтение своей PDF-копии книги правил.

- **Без регистрации и серверов.** Все данные хранятся только в вашем браузере (`localStorage`).
- **Работает офлайн** и устанавливается на телефон/компьютер как приложение (PWA).
- **Резервные копии и обмен** — через JSON-файлы: «Персонажи → Резервная копия / Импорт копии», экспорт отдельного персонажа.

> Неофициальный фанатский проект. Cyberpunk RED принадлежит R. Talsorian Games. Текст книги правил в проект не входит: PDF открывается локально и никуда не загружается.

## Хостинг

Сайт полностью статический: после `npm run build` в папке `dist/` лежит всё, что нужно разместить на любом хостинге.

### GitHub Pages (основной вариант, бесплатно)

Workflow `.github/workflows/deploy.yml` на каждый push в `main` прогоняет тесты, собирает сайт и публикует его.

Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем перезапустите workflow (Actions → «Test and deploy to GitHub Pages» → Run workflow) или сделайте push в `main`.

Адрес сайта: `https://<пользователь>.github.io/<репозиторий>/` — для этого репозитория `https://acak1221.github.io/Cyberpunk-beyond/`.

### Vercel / Netlify / Cloudflare Pages

- **Vercel:** импортируйте репозиторий — настройки берутся из `vercel.json` (сборка `node scripts/build.mjs`, папка `dist`). Переменные окружения не нужны; старые переменные Supabase можно удалить.
- **Netlify:** настройки в `netlify.toml`.
- **Cloudflare Pages:** команда сборки `node scripts/build.mjs`, папка вывода `dist`.

## Разработка

Нужен только Node.js 20+; зависимостей нет.

```bash
npm run dev       # http://127.0.0.1:5173 — исходники из site/ без кэша
npm test          # проверка синтаксиса + ~1100 тестов (node --test)
npm run build     # сборка в dist/ (с service worker для офлайна)
npm run preview   # сборка и просмотр dist/ на http://127.0.0.1:4173
```

## Структура

| Путь | Что там |
| --- | --- |
| `site/index.html` | Точка входа; порядок подключения скриптов важен, `app.js` — последним |
| `site/app.js` | Оболочка приложения: навигация, лист персонажа, кубики, обзор |
| `site/local-store.js` | Сохранение в браузере, синхронизация между вкладками, восстановление повреждённых данных |
| `site/pwa.js`, `site/sw.js`, `site/manifest.webmanifest` | Установка и офлайн-режим |
| `site/rules.js`, `site/catalog*.js`, `site/defenses-extra.js` | Справочник правил и каталог снаряжения |
| `site/*-tools.js` | Отдельные модули: бой, NET, медицина, ремонт, ведущему и т. д. |
| `site/book*.js`, `site/vendor/pdfjs` | Чтение и поиск по своей PDF-копии книги (pdf.js) |
| `scripts/` | Сборка, локальный сервер и проверка |
| `tests/` | Тесты модулей и интеграции (`node:test`) |

## Данные и перенос

Данные лежат в ключе `nightcity-red-v1` в `localStorage` выбранного браузера и сайта. Если сменили браузер, устройство или адрес сайта — экспортируйте резервную копию на старом месте и импортируйте на новом. Если сохранённые данные не удалось прочитать, приложение откладывает исходную копию в `nightcity-red-v1:recovery` и предлагает скачать её.
